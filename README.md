# Portfolio BUT 2 — Lucas Requena

Portfolio de stage (2ᵉ année de BUT Informatique), réalisé chez **De Niveau**
(marque *Audit & Qualité*), mai – juillet 2026.

Site statique, sans dépendance ni build : ouvrez `index.html`.

## Pages

- **Accueil** — contexte de l'entreprise, du sujet, et synthèse des savoir-faire.
- **Technique** — développement, système / réseau, données, sécurité.
- **Suivi de projet** — cadrage, qualité du code, versionnement.
- **Intégration en entreprise** — besoin métier, contraintes économiques, autonomie des utilisateurs.

Chaque savoir-faire est illustré par des **traces** issues du travail réel (captures,
schémas, extraits de dépôt) et suivi d'un bilan auto-évalué.

## Structure

```
index.html · technique.html · suivi-projet.html · integration.html
assets/css/style.css · assets/js/portfolio.js · assets/img/
```

Navigation entre pages dans l'entête (toujours visible) ; navigation entre sous-pages
par onglets, flèches ‹ › ou touches ← →.
